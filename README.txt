WHISKY COLLECTION — VERSION IPHONE

Application web progressive (PWA), conçue pour être ajoutée à l'écran d'accueil d'un iPhone.

Pour l'utiliser comme une app : publier le dossier sur une adresse HTTPS, puis ouvrir cette adresse dans Safari > Partager > Sur l'écran d'accueil.

Les données sont stockées localement sur l'iPhone via localStorage. Export JSON disponible dans Plus.

Cette version ne comprend volontairement aucun scan de bouteille.
